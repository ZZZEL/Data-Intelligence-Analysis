# 企业连接 Demo 完整度审计

审计日期：2026-09-01

## 结论

当前 Demo 已完成“企业连接登记台账”的基础闭环，但尚未完成“发现企业资源 → 明确授权 → 配置用途 → 形成知识来源或实时查询能力 → 查看运行与审计记录”的演示闭环。因此，在“不接真实后端、但所有操作、字段、选项和状态都要演示”的标准下，当前仍不完整。

仓库现有静态检查和闭环检查均通过；它们验证的是当前 README 声明的窄范围（登记、测试、编辑、启停、删除），不代表正式 PRD 的企业连接范围已覆盖。

## 已满足

- 列表、搜索、部分状态筛选、汇总统计。
- 登记、详情、编辑、草稿测试、列表复测、启停确认、删除确认。
- MCP Client、数据库只读视图、企业 API、受控数据服务四种技术接入方式。
- 名称、用途、地址、凭据引用、业务域、Owner、数据范围、行数、超时、回溯、资源白名单、脱敏开关。
- 新连接默认停用、凭据脱敏、启用前校验、启用中不可删除、保护连接不可删除。

## P0：演示主故事缺口

1. 缺少资源详情：Schema、字段语义、主键、更新时间字段、敏感字段、样例数据和预览状态。
2. 缺少资源用途配置：同步为治理后知识、发布为实时查询能力、两者结合或暂不使用。
3. 缺少知识来源对象和表单：企业连接引用、资源标识、内容/字段映射、治理凭证、ACL、同步方式、水位和来源状态。
4. 缺少同步批次：全量/增量、起止水位、新增/更新/撤回/失败/跳过、错误、重试和发布结果。
5. 缺少查询能力：输入参数、输出字段、受控查询模板、权限、样例调用、数据时点、快照 ID 和查询记录。
6. 缺少可见的发布链路：测试、审批、发布、灰度、停用、回滚；当前编辑直接覆盖原对象。

## P1：字段、选项与治理缺口

- 企业连接共用字段缺少适用场景、不适用条件、输入输出、依赖与版本约束、兼容范围、所需权限、敏感范围、执行类型、幂等性、审计要求、重试、配额、用量指标、失败降级、固定样例、版本和变更说明。
- MCP 缺少 Server ID、Transport、Tools/Resources Schema 摘要、发现时间、发现版本和允许暴露子集。
- 不同技术方式共用同一套“服务地址 + 凭据”表单；缺少数据库、API/ERP、MCP 的类型专属字段和认证选项。
- 独立状态轴未实现：发布、测试、审批、健康、凭据、启用状态目前被合并或省略。
- 缺少样例调用、影响查看、凭据轮换、依赖引用、用量、运行记录和可见审计。
- 停用、删除或扩大授权范围前没有展示受影响的知识来源、知识库、Skill 与任务。

## 已发现的现有缺陷

1. MCP 种子连接包含 `orders` View，但 MCP 候选目录只返回 Tool/Resource；编辑保存会静默丢失该资源。
2. “重新发现”会直接选中全部硬编码候选资源，没有区分发现与授权。
3. 用途和 Owner 在界面标必填，但动作层未一致校验。
4. 连接测试只判断地址文本；未验证凭据，保存后凭据状态固定为“有效”。
5. 测试成功后修改地址、凭据或类型，不会使测试结果失效。
6. 失败复测会自动停用连接，但 Toast 未说明该副作用。
7. 表单汇总错误位于滚动区底部；提交失败后不滚动、不聚焦，也未按字段提示，当前视口中不可见。
8. 禁用删除按钮的原因主要依赖 `title`，键盘、触摸和读屏场景不够可靠。

## 建议的 Demo 完成结构

企业连接详情使用五个页签：

1. 概览
2. 授权资源
3. 使用配置
4. 运行记录
5. 安全与审计

至少提供两条全 Mock 闭环：

```text
连接 → 发现候选资源 → 预览 Schema/样例 → 显式授权
→ 创建知识来源 → 配置映射/同步 → 模拟同步 → 知识库显示来源与批次
```

```text
连接 → 发现候选资源 → 预览 Schema/样例 → 显式授权
→ 发布查询能力 → 配置参数/权限 → 样例调用
→ 显示模拟结果、数据时点、快照 ID 与查询记录
```
