# 数据智能分析轻量用户端 Demo

这是一个单一的 GPT 式聊天界面，用于演示数据智能分析产品在独立使用场景下的完整工作过程。AI 的业务分析正文统一按 Markdown 渲染；正文之前使用可编辑的思考文本、五步 Plan 以及按时序穿插的 Tool／RAG 节点。这些内容始终位于同一条 AI 回答内，不拆成多次回答或独立任务页。

思考过程完成后不再等待修订，正文会立即开始输出，同时开放 Plan 之前初始思考正文的编辑能力。该段文字直接切换为编辑态；保存后在原句中逐处显示差异：未改文字保持原样，删除文字使用浅灰删除线，新增文字在输入位置以蓝色标识。修订会重新生成 Plan、重新触发内部知识检索／Web Search／数值计算、重新生成后续思考与最终正文；不生成新的用户气泡，也不出现独立编辑器或新旧全文总结块。

当前用户端包含轻量对话和报告模板管理，不再包含调用演示、调用评估、任务基线、权限校验、持久化回执或独立结果页面。

## 访问方式

在项目根目录（包含 `package.json` 的目录）启动静态服务：

```bash
npm run serve
```

然后访问：

```text
http://127.0.0.1:8780/user-client/#/chat/new
```

报告模板页：

```text
http://127.0.0.1:8780/user-client/#/templates
```

首页使用固定路径 `#/chat/new`，点击产品名称和“新建对话”均回到此页；首次发送消息后才创建对话记录并进入 `#/chat/:id`。铜采购案例仍可通过 `#/chat/copper-decision` 访问。产品另提供 `#/templates`、`#/templates/new` 和 `#/templates/:id` 路由；其他地址均显示为不存在，不会回落到聊天页面。

## 演示内容

- GPT 式会话列表、聊天流和消息输入框；
- 预置三个会话：完整的铜采购案例默认置顶；普通“对话记录”默认包含“通用问答”和“分析结果解读”，各提供两轮问答，直接展示消息，不展示分析流程。
- 每条会话右侧的三点菜单提供置顶／取消置顶、重命名和删除；存在置顶会话时显示“置顶”分组，其余会话列入“对话记录”。
- 会话顶部只展示标题；铜采购案例提供“重新演示”按钮。
- 用户提问与四个上传文件；
- 开头用一组充分展开、长短有明显差异的用户可读分析说明交代判断框架、初始测算、风险口径和待核验假设；AI 业务正文统一按 Markdown 渲染，以自然语言段落、标题、列表、引用和表格呈现分析内容；
- 五步分析路径作为开头的总体 Plan，只展示真实分析任务，不把编辑思考作为计划步骤；
- 全流程只展示 3 个关键节点：内部知识检索、Web Search 与数值计算；
- 开场大段思考之后展示总体 Plan，再用一段过渡思考进入节点；每个节点后都紧跟长短不一的思考正文，避免等距、等量的机械节奏；
- 节点类型使用 Tool 与 RAG；节点外层直接使用对应能力图标，完成后不展示输出，也不提供展开明细；
- 思考修订：思考完成与正文开始输出同时发生；仅可点击 Plan 前的初始思考正文，底部只用提示文字告知，不放置操作按钮；
- 保存修订后，原文中的删除、新增与保留部分直接按行内差异呈现，并从该思考重新规划、重新调用、重新思考和重新生成正文；
- 最终结论、损益测算、方案路径、行动清单和一份汇总报告；
- 完整流程重新播放，思考结束后不中断正文输出；
- Markdown 正文在稳定消息节点内逐字追加，执行轨迹只更新对应步骤的状态与明细，不重建聊天页面或已完成内容；
- 系统减少动态效果时直接展示完整 Markdown 与执行明细；
- 新对话初始页将图标、标题、说明和输入框整体居中，不显示会话标题栏；首次发送后切换为正常对话布局。
- 上传文件、发送消息，以及唯一报告的右侧抽屉预览与下载演示；下载与关闭按钮位于顶部，正文独立滚动到底部，也可通过遮罩或 Esc 关闭。
- 头像区只展示头像和姓名，展开后可进入运营端或选择退出登录。
- 在用户端管理报告模板：新建、编辑和删除；编辑时可增删、上下移动或拖拽报告章节，逐章选择是否需要图表，并实时预览结构。

## 演示边界

- 所有内容均为前端固定模拟数据；
- 不连接真实模型、企业数据库、知识库、Web Search 或文件解析服务；
- 新建会话、消息、上传文件以及会话的置顶、重命名和删除操作只保存在当前页面内存中，刷新后恢复预置数据；切换会话时保留各自消息；
- 退出登录与运营端一致，仅演示确认交互，尚未接入身份认证，不结束本地会话；
- 报告模板的新建、编辑和删除同样只保存在当前页面内存中；
- 报告预览与下载均为一份 PDF 报告的前端模拟，不代表真实文件生成服务；
- 输入框会随内容增高，并在达到最大高度后转为内部滚动；
- 当前仅按桌面端演示设计。
