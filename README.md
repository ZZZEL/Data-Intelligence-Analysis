# 数据智能分析工具 Demo

本目录是数据智能分析工具的统一演示项目，包含两个桌面 Web 子应用：

- `user-client/`：轻量用户端，用于演示对话、文件上传、分析过程、必要询问与结果交付；报告由 AI 根据任务、证据和交付目标自由组织，不提供模板配置；
- `ops-console/`：运营端，用于演示知识库、文档、数据接入、检索与模型配置管理。

两个端属于同一个 Demo 项目，通过相对地址双向跳转；为避免样式、Mock 状态和路由相互影响，源码仍按子应用隔离。

点击侧栏底部的头像展开账户菜单：用户端选择“运营端”，运营端选择“用户端入口”，即可切换界面。

## 项目结构

```text
Data-Intelligence-Analysis/

├── package.json           统一启动与检查命令

```

## 启动与访问

在项目根目录（包含 `package.json` 的目录）执行：

```bash
npm run serve
```

访问地址：

- 默认入口：`http://127.0.0.1:8780/`（自动进入用户端）
- 轻量用户端首页：`http://127.0.0.1:8780/user-client/#/chat/new`
- 运营端：`http://127.0.0.1:8780/ops-console/#/knowledge`

## 文档切片 Demo 契约

文档处理先提供“自动切片、语义切片、自定义切片”三个类型。自定义切片固定按以下顺序展示五种方法：

1. 结构切片：依据解析阶段产生的标题、段落、列表和表格等块级结构切分；
2. 分隔符切片：在单个“优先切分边界”下拉中选择八个常用符号之一，默认 `\\n\\n`（段落 / 空行）；超长内容由系统自动按更细边界递归拆分，最后按字符上限兜底；
3. 固定长度：按每片字符数形成等长窗口，尾片可不足，并按重叠率计算相邻窗口的重复字符；
4. 按页切片：按解析得到的连续页分组；
5. 整篇切片：短文档整体作为一片，超长时按配置改用自动切片或停止处理。

新保存的分隔符配置统一使用 `mode: "separator" + separatorType`，不再保存或展示 `boundaryMode`。下拉中的符号以代码样式展示，名称保持普通文本。递归是分隔符切片的默认执行机制：先使用所选边界，仅对超长片段继续尝试更细边界，最后按字符长度兜底。旧 `mode: "recursive"`、`ING-RECURSIVE` 以及历史 `boundaryMode` 配置仍可读取，并迁移为以段落或原有分隔符为首选边界；旧预置不再出现在新建流程。分隔符和固定长度在 Mock 动作层均会生成对应的实际预览切片，而不只是保存界面参数。

## 检索融合 Demo 契约

混合检索固定启用关键词检索和语义检索两路召回，默认使用 RRF 融合排序并去重。RRF 方法、`rrfK=60` 和两路候选规模属于代码配置，不向运营人员开放权重、百分比或 Slider；页面仅允许配置 Rerank、最终 Top K 与最低相关度。历史请求中的 `keywordWeight`、`semanticWeight` 会被兼容读取后忽略，不写入新的运营设置或运行快照。

## 模型管理 Demo 契约

模型管理分为 LLM、向量模型和 Rerank 模型三个板块。LLM 预置 DeepSeek-V4-Pro、Qwen3.8-2.4T-A95B 和 Qwen3.5-397B-A17B；LLM 配置只维护模型名称与连接信息，不采集或校验参数规模。所有连接测试均为本地模拟，默认回答生成引用 DeepSeek-V4-Pro。

## 演示边界

- 两个端均为纯静态交互 Demo，仅使用本地 Mock 数据；
- 不连接真实模型、知识库、企业数据库、Web Search、Skill、Tool 或 MCP 服务；
- 页面中的能力调用、进度、文件处理和结果均为演示模拟；
- 当前仅定义桌面端产品形态，不包含移动端。
