# 管理操作闭环审计

本记录只审计当前知识 / RAG 与部分配置运营专项原型的已实现闭环，不代表完整运营端范围，也不覆盖正式 PRD 所要求的运行管理、知识来源/批次/版本、真实企业数据导入、模型路由与 Prompt/策略等能力。

审计目标：在本专项原型范围内，运营人员从具体对象列表或详情发起变更，能够完成验证、生效、观察和恢复；未实现的正式运营能力不据此判定为退出产品范围。

## 统一原则

```text
在所属对象中发现问题或发起变更
→ 在对象内编辑、校验或预览
→ 查看影响范围
→ 明确确认后生效
→ 页面回执并同步对象状态
→ 按对象自身支持的方式恢复或重新设置
```

全局 Query 检索设置是单一运行时参数对象，保存后直接对后续 Query 请求生效，不建立“复制草稿 → 审批发布 → 应用到知识库”的版本流程。检索测试可携带页面上未保存的临时设置，但不会回写全局值。运营端不提供分析口径配置；相关计算逻辑由技术侧实现。文档处理方案由代码预置，没有独立运营管理入口，只在知识库创建和知识库文件导入中允许选择并编辑本次参数；文档管理公共池上传复用原第 3 步显式配置并提交解析，但不进入第 4 步文档处理。Skill、Tool 与可视化生成均由底层系统预置，不属于运营端管理对象，但用户端仍可展示实际调用。报告由用户端 AI 根据任务、证据和交付目标自由组织；用户端与运营端均不提供模板入口、路由或配置。本专项原型 IA 不提供运行概览或独立配置记录页面。

页面级操作遵循统一承载规则：返回、页面身份、搜索、筛选、视图工具和主要动作都进入单行 `PageHeader`，左侧保持页面身份，右侧集中操作；业务内容使用开放 `page-content`，不通过无意义的最外层 Panel 制造额外层级。

## 指标单一归属

- 切片、Embedding 与索引处理：知识库创建/文件导入流程中的文档处理步骤。共享方案与底层索引快照不作为可见运营对象。
- 知识库文件列表呈现“解析中 → 切片中 → 向量化中 → 索引中 → 可检索 / 处理失败”一套生命周期。文档管理是原文件公共池，上传页直接复用原第 2 步，解析页直接复用原第 3 步的全部配置和交互，步骤条只展示“上传 → 解析”两步。上传后登记到公共池并等待用户提交解析配置；提交后返回列表由后台完成解析。不选择目标知识库，不另设解析完成页、逐文件状态面板、动效或解析结果预览，也不生成公共池切片、向量或索引。文档管理不提供主动加入知识库操作；文件详情右侧常驻知识库选择器，无引用时显示占位，存在引用时仅查看所选知识库切片，不重复显示引用列表。建立引用和完成知识库解析、切片、向量化与索引只能通过知识库管理流程。
- 新增/修改切片、重新处理或显式替换文件会重新生成向量，影响提示使用“Embedding Token 消耗”口径；删除仅说明向量/引用被移除。
- 同名同内容文件只跳过，不增加文件、向量或 Token 消耗；同名不同内容必须由用户明确选择更新原文档或另存为同名新文档。更新沿用稳定 `document_id`，候选结果就绪前旧索引保持可用，成功后同步所有引用该文档的知识库。
- 向量模型与 Rerank 模型的名称、API 地址、脱敏 API Key 和连接状态：模型管理；向量维度只属于向量模型。主推理模型、模型版本、内部 ID、服务来源和引用关系统一不进入可见列表。
- 知识库只归属内容、文档处理、向量模型与内容索引状态，不归属全局 Query 检索设置或 Rerank 模型。知识库检索可用性不以 Rerank 开关或连接为前置条件。
- 全局 Query 检索设置只归属问题检索运行时；系统固定项不开放运营编辑，运营可配项保存后全局生效。
- 检索可用性与命中证据：检索引擎/检索测试；测试只选知识库，页面运营评估只汇总返回切片数、有效证据数、证据覆盖度与结果相关性，不展示算法分数或阶段耗时。
- Skill、Tool 与图表生成属于底层运行时能力，不归属运营端目录、状态或操作；用户端可展示任务中的实际调用。
- 模型级聚合的 API 请求次数、输入 Token 和输出 Token：消耗统计；按统一模型与时间区间聚合，不展示推理调用次数、每日明细、预测、阈值、提醒或场景归因。
- 本专项原型未实现运行概览或配置记录中心；正式产品是否提供及其范围以 PRD 为准。
- 消耗数据由推理服务聚合，仅保存统计结果，不保存问题、回答、模型输出、思考过程、任务日志或报告正文。

## 自动检查

`tests/static-check.mjs` 检查所有 `index.html` 本地资源引用、源文件语法、无外部 URL、无 `fetch` 和无 ES Module，并执行通用 `PageHeader` 的单行 DOM 契约以及关键页面结构回归，保证 Demo 可通过 `file://` 直接打开。

`tests/closed-loop-check.mjs` 直接验证 Mock 状态与统一动作层，包括四步建库、服务器连接测试/可访问数据库列表加载/目标数据库必选/账号密码校验/明文不落状态/无 Schema 范围设置、向量模型固化且与 Rerank 解耦、文件单一生命周期、重名同内容跳过/不同内容替换、切片预览数据与新增切片/文件替换后的向量化 Token 影响、MinerU 参数白名单与图片理解限制、文档公共池复用第 3 步显式提交解析且不生成切片、知识库原文件/切片预览、模型保存自动测试/API Key 脱敏/全局及 Key 级 Rerank 引用保护、全局 Query 检索设置校验与保存生效、临时未保存设置只影响当次测试、检索运营评估、知识库检索启停，以及 API 密钥知识库白名单、全局/独立策略、一次展示、无数量 footer、启停/删除闭环。检查还会反向约束运营端不注册 Skill、Tool 与可视化管理页面、状态或动作。

## 本专项原型 IA 回归清单

- 根地址默认进入知识库管理；侧栏不出现运营概览或配置记录入口。
- 四个分组标题为灰色无图标文本；所有可点击导航项均带图标；侧栏不出现能力管理、Skill 目录或可视化能力。
- 模型管理位于系统配置分组下；向量模型和 Rerank 模型使用上下两个表格板块及同一四列网格，不使用类型/状态筛选；只有向量表显示连接后读取的向量维度，Rerank 保留空维度槽以对齐连接状态和操作列。两表都将状态和测试时间合并为连接状态，并提供测试、编辑和删除。
- PageHeader 只有一处 H1；新建/启停/导入、搜索、筛选和视图控制均位于同一行右侧操作区。
- 检索测试不恢复无语义的整页外框。
- 知识库创建是四步全页流程；定义步骤为纵向表单，其中向量模型/向量维度为并列一行，底部为“取消 / 仅创建 / 创建并导入”。
- 上传步骤不重复上一步摘要；多文件以逐行状态展示，底部只有“取消 / 导入”。
- 解析步骤只配置 MinerU 结构化抽取；切片属于第 4 步的文档处理策略。
- 侧栏和独立路由不出现文档处理策略；运营动作层不提供共享方案的新建、编辑、复制、查看、试切片、启停或状态管理。知识库创建和已有知识库导入共用第 4 步，仅保留预置方案选择与本次切片参数，关联信息和索引内容由代码规则固定。文档管理只复用原第 2、3 步的页面内容，步骤条展示“上传 → 解析”，路径仍为 `local-documents/upload`；点击“开始解析”即返回文档管理，后台处理结果由列表状态反映，不再渲染独立解析进度或完成组件。
- 知识库绑定向量模型后不可切换；模型管理中新接入且保存时自动测试通过的向量模型应成为建库模型来源。知识库不绑定 Rerank 模型或全局 Query 检索设置；被全局设置选中的 Rerank 模型在更换引用前不允许删除。
- 检索配置页只管理一份全局 Query 检索设置，系统固定混合召回并派生候选规模；运营可修改两路融合权重、Rerank、Top K 及 0.4–0.9 最低相关度，不存在单文件上限；不出现配置列表、版本、草稿、发布、回滚或应用到知识库。
- 知识库详情和检索配置均有检索测试快捷入口；测试页为左右工作区，左侧只选知识库，检索按钮位于输入框内，只保留运营评估和证据，不出现检索配置/版本/状态选择或重复说明标题。从设置页进入时可临时测试未保存值，但不回写全局设置。
- 知识库列表名称可进入详情；本专项原型详情只展示当前聚合文件视图，尚未实现入库批次与知识/内容/索引版本入口。正式实现保留稳定文档标识和不可变内容版本；文件列表的单一生命周期只是展示聚合，不是后端权威状态源。
- 文件预览可切换/下载知识库内文件，并排展示源文档和“全部切片（N）”；无状态、独立源文档栏头或代表切片汇总。卡片支持单张展开和再次/外部点击收起；新增切片前提示重新生成向量与 Embedding Token 消耗。
- 重名同内容导入跳过；重名不同内容由用户选择更新原文档或另存。更新沿用稳定 `document_id`，内部候选处理成功后同步引用库并产生向量重建 Token 影响；产品只显示当前内容，不渲染内部快照或历史版本。
- Skill、Tool 和可视化生成由底层系统预置；运营端不保存对应目录数据，不注册路由、页面或管理动作。用户端任务执行中的 Skill、Tool 调用展示保持不变。
- API 密钥与消耗统计靠近账户区；账户可见内容只有头像和名称；`#/api-access` 仅保留为兼容路径。
- API 密钥仅用于其他产品调用检索 API；创建拆为“名称与知识库 → 检索策略 → 获取 API Key”三步，完整 Key 仅展示一次。列表依次显示名称、API Key、可访问知识库、检索策略、状态、最近使用时间、创建时间、操作，其中知识库只显示数量、策略只显示“全局 / 独立”，状态为“已启用 / 已禁用”，且不显示数量 footer。查看页用静态文本回显名称、脱敏 Key、知识库名称，以及 Rerank 模型、最终 Top K、相关度阈值；不显示知识库 ID、状态、策略说明，也不出现角色、权限等级、身份传递、IP 白名单、RPM、到期或“永久作废”。删除后记录从当前目录移除。检索 API Key 与检索服务连接凭证分属下游调用和上游接入，不混用。
- 消耗统计以“Token 消耗 / API 请求次数”页签分离两类指标，页签行常驻只包含 LLM 名称的模型筛选，页头提供预设/自定义时间区间。模型和时间共同驱动当前页签的三项摘要与单张图表，图表标题保持固定。不出现向量与 Rerank 模型、模型类型后缀、推理调用次数、每日明细、预测、阈值、提醒、场景归因或配置入口。
